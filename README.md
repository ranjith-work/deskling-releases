# Deskling releases

Public downloads for [Deskling](https://deskling.app), the little companion that lives on your Mac desktop.

**Download the latest version:** [deskling.app/get](https://deskling.app/get), or grab `Deskling.dmg` from the [latest release](https://github.com/ranjith-work/deskling-releases/releases/latest).

## Requirements

- macOS 12 (Monterey) or later
- A Mac with Apple silicon (M1 or later)

## Installing

1. Open `Deskling.dmg` and drag Deskling into Applications.
2. Open Deskling from Applications.

Deskling is signed and notarized by Apple, so it opens like any other app.

## Updates

From version 0.2.0 on, Deskling checks for updates by itself and asks before installing one. You can also choose **Check for Updates…** from the menu bar icon.

If you installed 0.1.0, download the latest version once by hand. After that, updates arrive automatically.

## Verifying a download

Each release lists the SHA-256 checksum of `Deskling.dmg`. To check yours:

```sh
shasum -a 256 ~/Downloads/Deskling.dmg
```
